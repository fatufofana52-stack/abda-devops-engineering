Environment like Dev, Test, Stage, Prod
In software/cloud engineering, an environment is a place where an application or infrastructure runs.
Example:
Env Meaning
Dev Developers build and test new changes
QA/Test Testers check if the app works correctly
UAT Business users test before release
Stage/Staging   Almost the same as production, used for final testing
Prod/Production The real live system used by customers
